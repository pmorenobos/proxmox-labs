# 116 - Homelab con Proxmox desde cero

Material complementario del video donde se implementa un homelab con Proxmox VE desde cero.

Instalar Proxmox VE en equipo físico, configurar almacenamiento ya sea con un solo disoc o con ZFS Mirror/Raid1 y validar que el sistema quede listo para crear máquinas virtuales.
